### Создание виртуального окружения

python -m venv env

env - название папки с виртуальным окружением

### Активация виртуального окружения

необходимо зайти в cmd (в VS Code выпадающий список около кнопки "+")

env\Scripts\activate

### Установка библиотек

внутри виртуального окружения

pip install -r requirements.txt

### Сборка приложения

Запустить скрипт

build.bat

### Создание установщика

Запустить в приложении Inno Setup 6 скрипт

compiler.iss
